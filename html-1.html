¿Qué es HTML?

HTML (Hyper Text Markup Language) es el lenguaje estándar para estructurar el contenido en la web.

Etiquetas principales de HTML

Etiqueta Descripción
<h1>, <h6> Encabezados de diferentes niveles.
<p> Define un párrafo
<img> Incluye imágenes en la página.
<a> Crea enlaces a otras páginas.
